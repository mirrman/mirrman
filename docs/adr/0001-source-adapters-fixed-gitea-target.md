# Source adapters and a fixed Gitea target

Mirrman models GitHub, GitLab, and generic Git as interchangeable Source Platform adapters because adding public source platforms is an expected product extension; each adapter may optionally provide a Page Action. Gitea remains the fixed target module without a target adapter registry because the product specifically transfers public-platform repositories into a user-controlled Gitea instance, so a target seam would be hypothetical indirection.
